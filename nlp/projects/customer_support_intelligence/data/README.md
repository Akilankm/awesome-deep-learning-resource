# Data

This project uses **ready-made educational inputs** committed to the repository.

```text
data/
├── raw/
│   ├── support_tickets.csv
│   └── knowledge_base.csv
├── interim/
│   └── cleaned_tickets.csv          # generated by notebook
└── processed/
    ├── train.csv                    # generated by notebook
    ├── validation.csv               # generated by notebook
    └── test.csv                     # generated by notebook
```

## Why raw data is committed

Students should encounter the dataset as an analyst/data scientist would: **receive it, inspect it, discover patterns, formulate hypotheses and test them**.

The codebase therefore does not expose the corpus-construction recipe.

## Provenance

The dataset is educational synthetic/curated data created for this repository. This fact is disclosed so the project does not misrepresent provenance, but the construction mechanism is intentionally excluded from the student-facing workflow.

Do not treat project metrics as a public benchmark or production-quality estimate.
