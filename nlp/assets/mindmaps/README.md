# NLP Mindmap Assets

These SVGs are the visual causal models embedded in the concept notebooks.

Each map has the same engineering grammar:

```text
INPUT → MECHANISM → STATE / REPRESENTATION → OUTPUT
             ↑
         CONTROL KNOB
             ↓
         FAILURE LENS
```

Consistency is intentional: learners should become able to locate any NLP technique inside the same mental architecture and reason about downstream effects.

The maps are explanatory artifacts, not model architecture diagrams unless the notebook explicitly says so.
