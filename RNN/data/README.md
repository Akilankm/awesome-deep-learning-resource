# RNN text-classification data

This folder contains the local dataset used by the sentence-classification learning path and project.

- `sentence_sentiment_uci.csv`: 3,000 labelled sentences across Amazon, IMDb, and Yelp.
- `SENTENCE_SENTIMENT_DATASET_CARD.md`: provenance, schema, license, label semantics, and teaching purpose.

The data is committed so students can clone the repository and run the TensorFlow RNN/NLP notebooks without a dataset download step.
